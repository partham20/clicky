First public build of Clicky for Windows: an AI cursor buddy that looks at your screen when you press a hotkey, talks back, points and draws, teaches, dictates, and runs computer-use agents and MCP-connected apps.

## Download

- **ClickyApp-win-Setup.exe**: the installer. Per user, no admin prompt, no .NET install needed. Installs to `%LocalAppData%\ClickyApp`, adds Start menu and desktop shortcuts, and updates itself from this page.
- **ClickyApp-win-Portable.zip**: the portable build. Unzip anywhere and run `Clicky.exe`. It keeps settings in `%AppData%\Clicky` like the installed copy.
- The `.nupkg` files and `releases.win.json` / `RELEASES` are the update feed. Installed copies read them; you don't need to download them.

**The binaries are not code-signed yet**, so Windows SmartScreen shows "Windows protected your PC" on first run. Click **More info**, then **Run anyway**.

## Requirements

- Windows 10 version 2004 (build 19041) or later, or Windows 11, x64.
- Claude, one of:
  - **Subscription**: Claude Code installed and signed in (`claude` on the PATH, or set `claude.cliPath`).
  - **API**: an Anthropic API key (Settings › Claude; kept in Windows Credential Manager).
- A microphone for Talk and dictation. Speech-to-text runs locally with Whisper (downloaded on first use); an OpenAI key is only needed for the optional cloud voice engines.
- Optional, for the GPU local voice: an NVIDIA GPU with CUDA 12 and cuDNN 9 installed, then `speech.localProcessor` = `NvidiaGpu`.

## What's in it

- **Hotkeys and capture**: hold Ctrl+Alt to talk, double-tap Ctrl to type, Ctrl+Alt+A for Home. A screenshot of the monitor under the cursor is taken only while you ask, and never saved to disk.
- **Voice in**: local Whisper (Vulkan GPU, or CPU fallback), mic opens on key-down so the first word isn't clipped; cloud transcription optional.
- **Voice out**: Windows voices, cloud TTS, or the natural **Kokoro local voice** (default `af_heart`), streamed from the first comma so it starts talking quickly.
- **Talk end to end**: Claude answers by voice and acts on screen. Fast and deep routing, a warm Claude Code process, and JPEG screenshots keep replies quick.
- **Point, highlight and draw** on screen over any app; the overlays are click-through and excluded from screen capture.
- **Ink trail**: circle or underline things while you talk and Clicky knows what you meant.
- **Walkthroughs and app skills**: step-by-step guidance that waits for your clicks.
- **Text mode and documents**: type questions, drop in files.
- **Memory**: a profile Clicky keeps about you, editable as Markdown.
- **Dictation**: hold Ctrl+Win, or double-tap for hands-free, with spoken commands, a personal dictionary and cleanup.
- **Computer use**: agents that click, type and browse for you, preferring UI Automation, always asking before anything is sent, deleted or bought.
- **Clickys and Home**: your own assistants with chats, files and activity.
- **Routines**: scheduled agent runs, held during calls.
- **Connectors**: MCP servers and apps.
- **Morning suggestions** based on what you worked on.
- **Onboarding, Settings, auto-update and Report a bug** (bug reports are scrubbed of keys and your user name, and nothing is sent without you).

Clicky stays quiet during calls, screen sharing and Focus Assist.

## Per-PC settings

Hardware options live in `settings.json` per machine with safe defaults: `speech.localProcessor` (`Cpu` default, `NvidiaGpu` opt-in), `speech.localThreads` (0 = one per performance core), and `voice.useGpu` for Whisper.

## Updates

Installed copies check this page a minute after start and every 6 hours, download the next version in the background, and offer **Update and restart** in the tray. Settings, memory and downloaded models survive updates and uninstall.
